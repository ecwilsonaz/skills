# Clutter Catalog

Words and phrases to cut or replace, organized in the tradition of *On Writing
Well* ch. 3, 6, 7, 10. The categories follow Zinsser's diagnosis; the instances
are this skill's own catalog — common plain-language pairs plus additions in the
same spirit.

## Empty qualifiers / intensifiers — DELETE

Small hedging words dilute style and persuasiveness. Don't be somewhat confident;
be confident.

| Delete | Notes |
|---|---|
| very | occasionally earns emphasis; usually clutter |
| rather | "rather difficult" — how difficult, then? |
| quite | |
| pretty / pretty much | |
| too | when substituting for "very" |
| a bit / a little | timidity in word form |
| sort of / kind of | adds nothing but doubt |
| somewhat | |
| really | the same hedge wearing a different hat |
| fairly / relatively | unless the comparison is stated |
| in a sense | in which sense? |

## Wordy verb-phrases / weak verbs → strong verbs

| Weak | Strong |
|---|---|
| made a decision | decided |
| conducted an investigation | investigated |
| reached an agreement | agreed |
| provided assistance to | helped |
| is indicative of | indicates |
| gave consideration to | considered |
| took action | acted |
| performed an analysis of | analyzed |

**Prepositions draped onto verbs** that need no help: free **up**, meet **up
with**, test **out**, print **out**, continue **on**, circle **back around**,
raise **up**, enter **into** (an agreement). The verb was already complete.

Also fight fad/jargon verbs and nouns: **leverage, learnings, synergize,
operationalize, socialize (an idea), double-click on (a topic), circle back,
ideate, dialogue (v.), interface (v.), impact (v.), grow (the business),

equivalents: use, lessons, combine, carry out, share, discuss, follow up, think.

## Euphemisms & jargon — say the plain truth

Euphemism is clutter with a motive: it pads the phrase to soften or hide the fact.

| Euphemism | Plain truth |
|---|---|
| rightsizing / workforce optimization | layoffs |
| revenue shortfall event | missed the quarter |
| negative patient outcome | the patient died |
| unscheduled rapid disassembly | the rocket exploded |
| pre-owned vehicle | used car |
| corrective action was initiated | we started fixing it |
| food-insecure households | families going hungry |
| involuntary separation | firing |
| service disruption event | outage |

**Caution (reported prose):** the plain-truth column names what the euphemism
*typically* hides — it is not a licensed substitution. Before swapping, verify the
plain word states the same fact in context: "revenue shortfall event" is padding
you may cut to "revenue shortfall," but substituting "missed the quarter" would
assert a different fact. The fidelity gate outranks this table.

**Journalese to fight:** verbs and tags that exist only in news copy — officials
*slammed*, prices *skyrocketed*, a *firestorm* of criticism, *amid* growing
concerns, *begs the question* (for "raises"), *weighs in*, *breaks silence*,
*doubles down*, a *slew* of measures. Tired intensifier-clichés: "sent
shockwaves," "sparked outrage," "a perfect storm," "the elephant in the room."

## Directional-contrast clichés — name the direction, don't gesture at it

Stock "which-way" idioms that point vaguely at a contrast (or echo) the sentence
already makes concrete. The fix is not to delete and stop but to **land on the
substantive point** — say which way and why. Usually a neighboring clause or a
colon already carries the substance ("more books, not fewer"), so the idiom is
pure filler. **Watch for two in a row:** back-to-back "the other way" beats read
as a tic.

| Cliché | Fix |
|---|---|
| ran the other way / went the other way | name the actual direction ("asked for the opposite: more, not fewer"), or lead the reversal with "Instead," |
| cut the other way | "is an exception" / "upheld X" / state the holding plainly |
| ran the same way / went the same way | "matched it" / state what was shared |
| point the other way / point elsewhere | "say otherwise" / "contradict it" |

Not every contrast word is a tic: "the opposite," "instead," "otherwise" are
plain and fine. The tic is the *directional gesture* ("the other/same way,"
"point the … way") standing in for the concrete contrast.

## Crutch / throat-clearing phrases — DELETE

Word clusters that announce you're about to explain. If it's worth adding, add it;
if it should be noted, note it.

- "It is interesting to note that"
- "It should be pointed out that"
- "Needless to say"
- "The fact of the matter is"
- "As previously mentioned"
- "It goes without saying"

## Unneeded adverbs — DELETE

Judgment-adverbs that fake precision or pre-value a fact before the reader meets
it:

- arguably / decidedly / undoubtedly
- virtually / essentially / basically
- admittedly
- literally (as a mere intensifier)
- surprisingly / predictably / of course (they tell the reader what to feel
  before the fact arrives)

## Concept nouns → people + verbs

Dead abstractions standing in for action — reaction, expectation, hostility,
response — stall the sentence. Get people doing things. "The expectation among
staff is a rejection of the proposal" → "The staff expect the board to reject the
proposal."

## Usage distinctions to honor

flout ≠ flaunt · imply ≠ infer · disinterested = impartial · comprise = include
(the whole comprises the parts) · fewer (count) / less (mass) · can (ability) /
may (permission) · fortuitous = accidental · reject "myself" for "me," "author"
as a verb, "-wise" compounds (budgetwise), and the slashed "he/she" — recast the
sentence instead.
